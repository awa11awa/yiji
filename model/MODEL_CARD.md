# 忆迹 TinyBERT 消息二分类模型 v2.1.2

本版 TinyBERT 只区分 CHAT（聊天／非待办）与 SCHEDULE（日程候选）。不再输出事项类别、时间实体、状态或新建／变更／取消意图。完整事项提取由用户选定的云端 API 模型完成。

## 来源和重新训练

沿用中文 TinyBERT 4 层、312 隐藏维度、12 注意力头架构，在已校验的官方预训练编码器上重新微调一个二分类头。没有把 v2.0 的类别头改名后直接使用。

- 基础模型：huawei-noah/TinyBERT_4L_zh
- 固定 revision：152bf15d86715b41dd89c1e03cf5664963d9b005
- 官方原始权重 SHA-256：b4aec782e4a56727bb6ba1dcac8e6c3319460e58e11254f7e43a2dccee0c19c1
- 二分类头：CLS 与掩码平均向量拼接，线性层、GELU、Dropout、二分类输出。
- 实际训练：CPU PyTorch 2.14.1+cpu，Transformers 4.57.6，种子20261022，7轮，验证集选择第4轮。
- 训练／验证／测试：9,000／1,600／1,600条合成资料。句式模板按划分分开，词汇和随机噪声生成器共享；所有文本跨划分精确去重。
- 难负样本覆盖随机数字、重复字符、普通回复、作业完成回顾、知识问答与调试输出；正样本补充正式通知、时间待定、调课、体测与整份作业。
- 没有使用用户提供的真实通知训练；这些通知仅用于单独诊断。没有独立标注的真实消息测试集。

训练生成器只制作训练资料，不进入Android运行时。工具和完整报告见 tools/train_gate_v212.py、gate_training_report_v2.1.2.json。旧train_gate.py及gate_training_report.json用于复现旧v2.1模型。

## 路由策略

正文为空时才使用标题，避免群名影响。最大窗口384token，重叠96token；长消息先取各重叠窗口最高日程分数；若整段仍被判为非日程，再检查去重后的完整句段，避免少量安排被大量闲聊稀释。聊天分数阈值为0.5，由验证集选择；该分数不是经过真实消息校准的准确率。

应用另有无上下文数字/标点噪声过滤和重要通知漏识别保护；这两层不计入下表裸模型指标。无相关上下文的纯数字可直接分流；上下文中的短时间、更正消息保留分析。已忽略原文可以主动送云端复核。候选仍须通过云端提取及人工确认。

|---|---:|---:|
| 非待办误收 | 296/800 | 6/800 |
| 重要事项漏收 | 3/800 | 8/800 |
| 日程精确率 | 72.92% | 99.25% |
| 日程召回率 | 99.625% | 99.0% |

误收下降的同时，裸模型在此测试中的漏收增加5条。阈值仅依据验证集选择，留出集用于报告与替换门槛；不得将上述数字写成真实微信消息准确率或云端提取准确率。仍需补充去标识、独立标注的真实消息评测。
