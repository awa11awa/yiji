# 忆迹 TinyBERT 通用消息二分类模型 v2.2.1

区分 CHAT（聊天／非待办）和 SCHEDULE（事项候选），用于学习、工作、生活和办事消息。时间、地点、事项类别及变更关联由用户选定的 API 模型继续提取。

## 训练与选择

基础模型 huawei-noah/TinyBERT_4L_zh，revision 152bf15d86715b41dd89c1e03cf5664963d9b005；4层、312隐藏维度、12注意力头，CLS与掩码平均向量拼接后进入二分类头。

本次恢复上次续训检查点，先用完整旧合成训练资料9,000条等数据继续训练，再加入回忆照片与当前任务的对照样本。本轮使用旧合成资料9,000条、混淆训练资料2,280条、通用训练资料800条、额外通用训练资料6,888条以及30条真实训练通知的重复采样。额外资料包含前轮2,000条通用消息、800对正负对照、2,000条作业／报名／验证数字／普通闲聊回放、1,000条不同表达的旧照片与当前安排对照，以及288条既有运行回归案例重复采样。部分正样本有意重复训练。长消息按重叠窗口训练；长篇非待办消息额外训练完整句段，以匹配部署时的句段回退。训练窗口共21,526个。

阈值固定0.5。逐轮导出实际 ONNX，比较 UINT8 按通道、按张量、缩减量化范围以及 FP32 的验证结果，以通知召回、聊天误收和各场景表现共同选择。最终采用本轮第4轮的 fp32；发布图中只有一个模型。优化器重新开始，未声称恢复旧优化器状态。更早训练最初由旧UINT8图恢复近似浮点权重，量化舍入不能逆转。

验证集为旧合成1,600条、混淆480条、通用160条及真实9条。训练没有加入验证／测试原文或真实测试事件组；新增回放句式参考了旧合成开发集的错误类别。现有留出集已经多轮开发使用，以下是固定数据的开发对照，不称作新的盲测。轮次与导出方式依据验证结果选择，阈值固定0.5。

通用验证集有23条“老师让分析某句话的语法”样本，原标注为聊天，但它们也可能是实际作业。报告保留全部样本的严格指标；选择时另统计其余137条明确样本，不强迫模型将这23条判为聊天。测试集未删除或重标。

最后冻结编码器，仅以补充的口语打卡消息和既有资料回放微调分类头，使用原分类头软标签约束保留原有能力。分类头训练记录与运行回归锚点分数见报告。

## 部署

FP32 浮点 ONNX；ONNX opset17、IR8。模型45,598,276字节（约45.60 MB）。

SHA-256：`214976d1876a84089e43d0cfcda93c532238c91e1c93b55ecb445f3b04bad10f`。

384 token窗口、96 token重叠和长消息完整句段回退沿用既有策略。应用还包含数字噪声过滤、重要通知保护与人工复核入口，均不计入上表裸模型指标。APK与独立ZIP打入同一份已评估模型，发布时核对APK内的实际模型哈希。

PyTorch 2.14.1+cpu、Transformers4.57.6、Python ONNX Runtime1.31.0；Android/JVM使用ONNX Runtime1.23.2，发布流水线另外验证实际图、单元测试、Lint和固定签名。Android构建不触发训练。

训练与评测在初始化运行库前设置ORT_DISABLE_TELEMETRY=1，并关闭Hugging Face遥测。应用在创建推理会话前调用运行库的关闭遥测接口。

训练入口：`tools/refine_message_bert_v221.py`；额外训练样本：`tools/build_message_supplement.py`。完整逐轮记录与数据哈希见 [训练报告](message_bert_training_report_v2.2.1.json)。训练权重和私有资料另行保留，不放入公开源码。独立包包含ONNX、词表、元数据、模型卡及评估报告。
